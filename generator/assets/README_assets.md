# SimMOT rendering assets

This directory contains the background image and all five vehicle-appearance
classes used by the SimMOT v1.0 generator:

```text
background.jpg
passenger car/*.png
taxi/*.png
bus/*.png
other/*.png
large bus/*.png
```

Background and vehicle image assets used in SimMOT were created by the authors.
The files are included to support inspection and regeneration of the public base
sequences.
